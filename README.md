# jwan-marker-child-diptych

Jwan photo-to-marker-doodle diptych Skill.

## Features

- Preserve the supplied child photo in the upper half of a vertical 9:16 image.
- Redraw the same subject below using marker and child-doodle contours.
- Keep clothing, pose, identity, and the main action recognizable with generous white space.

![Case 01](examples/case-01.png)

## Usage

Use `$jwan-marker-child-diptych` followed by one child photo. Add optional color, caption, or signature requirements.
